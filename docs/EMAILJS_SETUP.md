# EmailJS setup

This site is a static export (GitHub Pages) with no server, so all outbound email — the
contact form and the Cost Estimator's "email me this draft" step — is sent client-side via
[EmailJS](https://www.emailjs.com). EmailJS's public key / service ID / template IDs are
meant to be used client-side; they are not secrets.

## 1. Create an account + email service

1. Sign up at https://www.emailjs.com (free tier: 200 emails/month).
2. **Email Services** → add a service (Gmail is easiest) and connect the mailbox you want
   mail to be sent from. Note the **Service ID**.
3. **Account** → **General** → copy your **Public Key**.

## 2. Create three templates

Create each template under **Email Templates** → **Create New Template**. For every
template, set **To Email** in the template settings (not the body) as noted below, and use
the exact variable names (`{{variable_name}}`) shown so they match what the code sends.

### Template 1 — `contact_form` (replaces FormKeep)

- **To Email:** `naim@evergreenridgetech.com`
- **Reply To:** `{{email}}`
- **Subject:** `New contact form inquiry from {{name}}`
- **Body:**
  ```
  Name: {{name}}
  Email: {{email}}
  Company: {{company}}
  Phone: {{phone}}

  Message:
  {{message}}
  ```

### Template 2 — `estimate_visitor_draft` (sent to the website visitor)

- **To Email:** `{{to_email}}`
- **Subject:** `Your Evergreen Ridge Technology project estimate (draft)`
- **Body (HTML):**
  ```html
  <div style="font-family: Arial, sans-serif; max-width: 600px; margin: 0 auto; color: #121212;">
    <img src="https://www.evergreenridgetech.com/email/logo.png" alt="Evergreen Ridge Technology" style="height: 60px; margin-bottom: 24px;" />
    <h1 style="font-size: 20px;">Your draft project estimate</h1>
    <p>Hi {{name}},</p>
    <p>Thanks for using our Cost Estimator. Here's a draft estimate for a <strong>{{project_type}}</strong> project based on what you selected:</p>

    <table style="width: 100%; border-collapse: collapse; margin: 16px 0;">
      <thead>
        <tr style="background: #0C3428; color: #F7F9F8;">
          <th style="text-align: left; padding: 8px;">Item</th>
          <th style="text-align: right; padding: 8px;">Hours</th>
          <th style="text-align: right; padding: 8px;">Cost</th>
        </tr>
      </thead>
      <tbody>
        {{{breakdown_html}}}
      </tbody>
    </table>

    <p style="font-size: 18px; font-weight: bold;">
      Estimated total: {{total_low}} – {{total_high}}
    </p>

    <p style="font-size: 12px; color: #64748B;">
      This is a non-binding, informational draft estimate only — not a quote or contract.
      Final scope and pricing are confirmed after a discovery conversation. See our
      <a href="https://www.evergreenridgetech.com/terms-of-service">Terms of Service</a> for details.
    </p>

    <p>Want to talk through the details? <a href="https://www.evergreenridgetech.com/contact">Get in touch</a> — we'd love to help.</p>

    <p>— The Evergreen Ridge Technology team</p>
  </div>
  ```
  > Note the triple-brace `{{{breakdown_html}}}` for the table rows — EmailJS (Handlebars-based)
  > renders triple braces unescaped, which is required since `breakdown_html` is an HTML
  > string (`<tr><td>...</td></tr>` rows) generated by the app.

### Template 3 — `estimate_lead_notify` (internal lead notification)

- **To Email:** `naim@evergreenridgetech.com`

## 3. Get the template IDs

Each template's ID is shown in the EmailJS dashboard (e.g. `template_abc1234`).

## 4. Configure env vars

**Local development** — copy `.env.local.example` to `.env.local` and fill in:

```
NEXT_PUBLIC_EMAILJS_SERVICE_ID=service_xxxxxxx
NEXT_PUBLIC_EMAILJS_PUBLIC_KEY=xxxxxxxxxxxxxxx
NEXT_PUBLIC_EMAILJS_CONTACT_TEMPLATE_ID=template_xxxxxxx
NEXT_PUBLIC_EMAILJS_ESTIMATE_VISITOR_TEMPLATE_ID=template_xxxxxxx
NEXT_PUBLIC_EMAILJS_ESTIMATE_LEAD_TEMPLATE_ID=template_xxxxxxx
```

**Production build (GitHub Actions)** — add the same five values as repository secrets
(**Settings → Secrets and variables → Actions**) named `EMAILJS_SERVICE_ID`,
`EMAILJS_PUBLIC_KEY`, `EMAILJS_CONTACT_TEMPLATE_ID`, `EMAILJS_ESTIMATE_VISITOR_TEMPLATE_ID`,
and `EMAILJS_ESTIMATE_LEAD_TEMPLATE_ID`. The deploy workflow (`.github/workflows/deploy.yml`)
reads these into the build step.

## 5. Test

Run `npm run dev`, submit the contact form and walk through `/cost-estimator` to completion,
and confirm both the visitor draft and the internal lead notification arrive with the logo
rendering and the breakdown table intact.
